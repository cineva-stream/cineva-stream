## About Cineva

Cineva is a cross-platform mobile app built with **Flutter**, designed to give movie and series lovers a clean, fast, and enjoyable experience. We focus on polished UI, smooth performance, and a seamless journey from discovery to watching.

## Highlights

- **Cross-platform:** One codebase, a native-feeling experience on Android and iOS.
- **Modern UI/UX:** Clean layouts, smooth animations, and a cinematic look.
- **Fast and lightweight:** Optimized for performance on everyday devices.
- **Landing website:** A responsive web presence built with Next.js and React.
